وش راح نبني اليوم؟

راح نبني قالب مشروع إبداعي داخل Claude Code — مجلد متكامل يحتوي على تعليمات الذكاء الاصطناعي، صيغة الـ Prompt الخاصة فيك، ومفاتيح الربط مع أداتين قويتين لتوليد الصور:

  • Higgsfield AI — لتوليد الصور مع صورة مرجعية
  • Fal.ai (موديل FLUX) — لتوليد الصور من النص فقط بدون مرجع

بعد ما نبني القالب، نسوي نسخة (Duplicate) منه ونحوّلها لمشروع شغّال — كل ما تبي مشروع جديد، تنسخ المجلد وتشتغل. ما يحتاج إعادة تركيب أو تركيب مفاتيح من جديد.

قبل ما تبدأ خذلك خمس دقائق وراجع المتطلبات الأساسية أولًا — كل التحضيرات تسويها مرة واحدة فقط في حياتك.
المرحلة 1

المتطلبات الأساسية

3 حسابات + 3 أدوات تركّبها على جهازك. تركيبة لمرة وحدة بس — بعدها كل مشاريعك الجاية تشتغل بدون أي إعداد.

أ. الحسابات المطلوبة

1. حساب Anthropic لـ Claude Code + Claude

  1. افتح الرابط: claude.ai
  2. اضغط على Sign Up (أو Sign In إذا عندك حساب).
  3. استخدم البريد الإلكتروني أو Google.
  4. أكّد بريدك إذا طلب منك ذلك.
معلومة نفس الحساب يفتحلك Claude (المحادثة) وClaude Code (الإضافة في VS Code).
للسعوديين وأهل الخليج · مهم إذا ما يوصلك رمز التحقق (OTP) على رقم جوالك أثناء التسجيل، Anthropic عندهم حل رسمي: عبّي نموذج Google Form هذا، وخلال يوم إلى يومين عمل راح يوصلك رابط تسجيل بدون الحاجة لرقم الجوال.

2. حساب Higgsfield لتوليد الصور بالمرجع

  1. افتح: higgsfield.ai
  2. اضغط Sign Up.
  3. سجّل بـ Google أو البريد.

3. حساب Fal.ai لتوليد الصور بـ FLUX

  1. افتح: fal.ai
  2. اضغط Sign Up.
  3. سجّل بـ Google أو البريد.
  4. راح يعطيك كريديت مجاني للبداية — كافي تجرّب فيه الدليل كامل.

ب. البرامج المطلوبة

4. VS Code المحرر

  1. افتح: code.visualstudio.com/download
  2. اضغط Download for Mac (أو Windows / Linux حسب جهازك).
  3. افتح الملف اللي حمّلته — راح يطلع لك تطبيق Visual Studio Code.
  4. اسحبه على مجلد Applications.
  5. افتحه مرة من Applications تتأكد إنه يشتغل.

5. Node.js مطلوب لـ Higgsfield CLI

  1. افتح: nodejs.org
  2. اضغط الزر الأخضر الكبير LTS (الإصدار المستقر).
  3. افتح ملف التثبيت → Continue → Continue → Install (أدخل كلمة السر إذا طلب).
  4. افتح Terminal وتأكد بالأمرين هذولا: 
    node --version
npm --version
    كلاهما لازم يطلع لك رقم إصدار.
وش يسوي Node.js؟ Node.js يخليك تركّب أدوات سطر الأوامر — نحتاجه لأن Higgsfield CLI مبني عليه. ما يحتاج تفهم تقنيًا — ركّبه ونساه.
لو طلعت "command not found" اقفل نافذة Terminal وافتح وحدة جديدة — أحيانًا الأداة الجديدة ما تظهر إلا بعد ما تفتح Terminal جديد.

6. تطبيق Claude للسطح المكتب اختياري — claude.ai في المتصفح يكفي

  1. افتح: claude.ai/download
  2. حمّل النسخة لـ Mac (أو Windows).
  3. افتح ملف التثبيت واسحب التطبيق إلى Applications.
  4. افتح التطبيق وسجل الدخول بحساب Anthropic.
المتصفح يكفي لو ما تبي تركّب تطبيق جديد، بس احفظ claude.ai في المفضلة. نحتاجه في المرحلتين 5 و6 لتوليد ملفين. كلاهما يشتغل نفس الشي.
انتهت الإعدادات الأساسية خلصنا 3 حسابات + 3 برامج. هذا الإعداد لمرة وحدة بس. كل اللي جاي بعد كذا هو البناء الفعلي.
المرحلة 2

تثبيت Claude Code في VS Code

إضافة Claude Code تدخل داخل VS Code وتعطيك واجهة محادثة تقدر تكلّمها بالعربي أو الإنجليزي، وهي تشتغل بالملفات والأوامر بدالك.

  1. افتح VS Code من Applications.
  2. اضغط على أيقونة Extensions في الشريط الجانبي (الأيقونة اللي شكلها 4 مربعات).
  3. اكتب في خانة البحث: Claude
  4. تأكد إن اسم الناشر "Anthropic".
    مهم دايمًا تأكد من اسم الناشر. فيه نسخ مزيفة من الإضافات المشهورة — النسخة الصحيحة دايمًا اسم ناشرها Anthropic.
  5. اضغط Install وانتظر شوي.
  6. بعد التثبيت، اضغط على أيقونة Claude اللي ظهرت في الشريط الجانبي.
  7. اضغط Sign in — راح يفتح لك صفحة في المتصفح. سجل دخولك بحساب Anthropic.
  8. ارجع لـ VS Code — تطلع لك واجهة المحادثة جاهزة.
تم Claude الآن مدمج في VS Code. يشتغل زي المحادثة — بس يقدر يقرأ ملفاتك، يعدّل عليها، يشغّل أوامر، ويستخدم الإنترنت.
المرحلة 3

تثبيت وربط Higgsfield CLI

Higgsfield CLI هو أداة سطر أوامر — تركّبها مرة وحدة على جهازك وتشتغل في كل مشاريعك. معلومات كاملة عن الأداة في higgsfield.ai/cli.

  1. افتح Terminal داخل VS Code: من القائمة View → Terminal (أو اضغط Ctrl + `).
  2. ركّب Higgsfield CLI بهذا الأمر: 
    npm install -g @higgsfield/cli
    يأخذ 30–60 ثانية. راح تشوف شريط تحميل.
  3. تأكد إن التركيب نجح: 
    higgsfield --version
    لازم يطلع رقم إصدار.
  4. سجل دخول حساب Higgsfield في الـ CLI: 
    higgsfield auth login
    راح يفتح لك صفحة في المتصفح — سجل دخولك بحساب Higgsfield.
  5. تأكد إن تسجيل الدخول نجح: 
    higgsfield auth status
    يطلع لك "authenticated".
تم Higgsfield الآن مربوط بجهازك. ما راح تحتاج تسوي هذي الخطوة مرة ثانية — كل مشاريعك الجاية تستخدمه مباشرة.
المرحلة 4

إنشاء مجلد القالب + تثبيت Higgsfield Skills

هنا نبني المجلد الأساسي للقالب. كل مشروع جديد بعد كذا راح يكون نسخة من هذا المجلد.

أ. إنشاء المجلد وهيكله

  1. افتح Finder (أو File Explorer لـ Windows). روح على سطح المكتب (Desktop).
  2. اضغط زر الفأرة الأيمن → New Folder. سمّه بالضبط: creative agent template واضغط Enter.
  3. افتح المجلد، وسوِّ المجلدات الفرعية التالية بنفس الطريقة:
    • assets (داخل المجلد الرئيسي)
    • داخل assets/ سوِّ 3 مجلدات: references, models, products
    • وفي المجلد الرئيسي أيضًا: generated-images
    شكل المجلد النهائي: 
    creative agent template/
├── assets/
│   ├── references/
│   ├── models/
│   └── products/
└── generated-images/
  4. اسحب المجلد على أيقونة VS Code (أو من VS Code: File → Open Folder → اختر المجلد).
  5. VS Code يسألك "Do you trust the authors?" — اضغط "Yes, I trust the authors".
  6. راح يظهر اسم المجلد في الشريط الجانبي مع المجلدات الفرعية اللي سويتها.
إذا ما تشوف المجلدات المخفية على Mac: اضغط Cmd + Shift + . (نقطة) — يظهر ويخفي المجلدات المخفية في Finder.
على Windows: من شريط View → Show → Hidden items.

ب. تثبيت Higgsfield Skills داخل القالب

الـ Skills هي حزم جاهزة تعلّم Claude يستخدم Higgsfield بشكل ممتاز — تحسين تلقائي للـ prompts، اختيار الموديل المناسب، ومخرجات أنظف. نركّبها داخل القالب مرة وحدة، وكل نسخة من هذا القالب تستفيد منها تلقائيًا.

  1. افتح Terminal داخل VS Code (إذا مسكّر).
  2. تأكد إنك داخل مجلد القالب: 
    pwd
    لازم يطلع المسار اللي ينتهي بـ creative agent template.
    ليش هذي الخطوة مهمة أمر التثبيت يحط الملفات داخل المجلد اللي إنت فيه. لو كنت في مجلد ثاني، الـ skills راح تنزل في غير المكان الصحيح.
  3. ركّب حزمة Higgsfield Skills: 
    npx skills add higgsfield-ai/skills
    يأخذ 30–60 ثانية. بعد ما يخلّص راح تشوف 4 مجلدات جديدة داخل .claude/skills/:
    • higgsfield-generate — توليد عام للصور والفيديو
    • higgsfield-soul-id — لثبات الوجه/الشخصية
    • higgsfield-product-photoshoot — تصوير منتجات احترافي
    • higgsfield-marketplace-cards — صور منتجات للمتاجر
  4. تأكد من ظهور المجلدات: 
    ls .claude/skills
    لازم تشوف الأربع مجلدات.
معلومات مهمة عن الـ Skills 1. الـ skills محصورة داخل هذا المجلد فقط — مو في النظام كله.
2. مشاريعك الثانية على نفس الجهاز ما تتأثر.
3. لما نكرر القالب لاحقًا (المرحلة 9)، الـ skills تيجي معه تلقائيًا.

توليد ملف README.md عبر Claude

ملف README.md يشرح المشروع بلغة بسيطة للبشر. بدل ما نكتبه من الصفر، نطلب من Claude يكتبه لنا.

  1. في VS Code، اضغط أيقونة New File. سمّه بالضبط: README.md (كل الحروف كبيرة، و.md صغيرة). اتركه فاضي.
  2. افتح تطبيق Claude أو claude.ai في المتصفح.
  3. الصق هذا الـ Prompt في محادثة Claude: 
    Generate a README.md file for a "creative agent template" project that I'll use as a reusable starting point for image-generation work in Claude Code (VS Code extension).

Project structure:
- README.md (this file) — explains what the project is
- CLAUDE.md — the prompt formula and rules Claude follows
- .env — holds the Fal.ai API key (will be created later)
- .gitignore — keeps .env private
- assets/references/ — reference images for Higgsfield
- assets/models/ — model photos / face references
- assets/products/ — product images
- generated-images/ — where the AI saves its output

What this template does:
- Generates editorial images using two AI tools:
  - Higgsfield AI (works with a reference image)
  - Fal.ai (FLUX model, text-to-image)
- Both tools follow the same prompt formula in CLAUDE.md
- This folder is a TEMPLATE — duplicate it to create a new project

How to use a project (after duplicating):
- Open the project folder in VS Code
- Open the Claude Code chat panel
- Drop assets into assets/references/, assets/models/, assets/products/
- Type plain-language requests like "Generate 5 images with Higgsfield using assets/references/reference.jpg" or "Generate 5 images with Fal.ai"

Format: clean Markdown, short, beginner-friendly. No emojis. No code fences wrapping the whole output.
  4. Claude يرد عليك بملف README جاهز. انسخ الرد.
  5. ارجع لـ VS Code، اضغط داخل ملف README.md الفاضي، والصق بـ Cmd + V.
    احذف الأقواس إذا موجودة أحيانًا Claude يحط النص داخل ``` (ثلاث علامات backtick) — احذفها من البداية والنهاية، خل النص الـ Markdown فقط.
  6. احفظ الملف بـ Cmd + S.
المرحلة 6

توليد ملف CLAUDE.md (دماغ المشروع)

ملف CLAUDE.md هو أهم ملف في المشروع — هو الدماغ. يحتوي على صيغة الـ prompt الخاصة فيك، والمتغيرات اللي يبدّل بينها Claude، وتعليمات استخدام أداتين الذكاء الاصطناعي.

  1. في VS Code، سوّ ملف جديد اسمه CLAUDE.md (كل الحروف كبيرة). اتركه فاضي.
  2. ارجع لتطبيق Claude، وافتح محادثة جديدة (أو استمر في المحادثة الحالية).
  3. الصق هذا الـ Prompt (يحتوي على صيغة التصوير الفني): 
    Generate a CLAUDE.md file for a "creative agent template" project in Claude Code (VS Code extension). This single file is the project's brain — it tells Claude everything needed to generate images using two AI tools.

Include these sections:

## 1. Project description
A brief one-paragraph description: an editorial image generation workspace that uses Higgsfield AI (with reference images) and Fal.ai (FLUX text-to-image). Both follow a shared prompt formula.

## 2. Prompt formula (USE THIS EXACT STRUCTURE — do not reword)
[image type], [camera angle], [subject focus], [clothing], [action/pose], [environment], [colour tone], [lighting and mood], [visual effects], [film stock + lens]

## 3. Variable examples
For each variable above, list 5–6 high-quality editorial example values (Vogue / fashion campaigns / Kodak Portra, Cinestill film stocks / golden hour, blue hour lighting / brutalist, Mediterranean, desert environments — that quality level).

## 4. How to call Higgsfield
This project has Higgsfield skills installed at .claude/skills/ — use them instead of calling the Higgsfield CLI directly.

When the user asks for editorial / fashion / lifestyle images, invoke the higgsfield-generate skill via the Skill tool. Pass it the generated prompt and (if available) the reference image path from assets/references/.

For product / brand shots, use the higgsfield-product-photoshoot skill instead.

The skill handles all Higgsfield CLI details, prompt enhancement, and mode selection automatically.

Save output files to ./generated-images/ with the naming convention: higgsfield-01-[image-type].png, higgsfield-02-..., etc.

## 5. How to call Fal.ai
When the user asks for Fal.ai (or FLUX), use curl. Load FAL_KEY from .env first:

set -a; source .env; set +a
curl -s -X POST "https://fal.run/fal-ai/flux/dev" \
  -H "Authorization: Key $FAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"[generated prompt]","image_size":"landscape_16_9","num_images":1}'

Each call returns JSON containing .images[0].url. Download the image:

curl -s -o ./generated-images/fal-[NN]-[image-type].png "[image-url]"

## 6. Rules
- Always follow the prompt formula structure exactly. Fill every bracket.
- Generate exactly the number of images the user asks for.
- Each image must use a different combination of variables.
- Save outputs to ./generated-images/ — create the folder if it doesn't exist.
- File naming: higgsfield-NN-[image-type].png or fal-NN-[image-type].png
- Never echo FAL_KEY in output.
- Reference images live in ./assets/references/.

## 7. Tool selection logic
- If the user says "Higgsfield" → use the Higgsfield section.
- If the user says "Fal.ai" or "FLUX" → use the Fal.ai section.
- If the user provides a reference image but no tool → default to Higgsfield.
- If the user provides no reference and no tool hint → default to Fal.ai.

Format as clean Markdown with H2 section headers. No emojis. No code fences wrapping the whole output — just raw Markdown.
    الصيغة لازم تبقى كما هي بالضبط الـ Prompt يطلب من Claude ما يغيّر صيغة الـ formula. لو غيّرها، الصق الـ prompt مرة ثانية وأضف: "use the formula EXACTLY as I wrote it."
  4. Claude يرد بملف CLAUDE.md متكامل. تأكد إن الـ formula صحيحة وانسخ الرد.
  5. ارجع لـ VS Code، الصق في ملف CLAUDE.md، احذف أقواس الـ code إذا موجودة.
  6. احفظ بـ Cmd + S.
  7. اختبر إن Claude Code يقرأ الملف. في محادثة Claude Code داخل VS Code، اكتب: 
    وش يسوي هذا المشروع وأي أدوات يستخدم؟
  8. Claude يرد ويوصف لك الـ formula والأداتين والقواعد. من هذي اللحظة، كل مرة تكلّم Claude داخل هذا المجلد — أو أي مجلد ننسخه منه — Claude يعرف وش يسوي.
المرحلة 7

ربط Fal.ai بالمشروع

نعطي Claude مفتاح Fal.ai، ونطلب منه يحفظه بأمان داخل المشروع. المفتاح يصير جزء من القالب — أي نسخة جديدة تستخدمه مباشرة.

  1. روح على لوحة تحكم Fal.ai → API Keys → اضغط Add Key → انسخ المفتاح.
  2. في محادثة Claude Code داخل VS Code، الصق هذي الرسالة — غيّر YOUR-KEY-HERE بمفتاحك الفعلي: 
    I want to use Fal.ai for image generation in this project.

Here is my Fal.ai API key: YOUR-KEY-HERE

Please do the following:
1. Create a .env file in the project root with FAL_KEY set to this value.
2. Create or update .gitignore to include .env so the key is never shared.
3. Do NOT print the key back to me in your response.
4. Confirm everything is ready.
    حذار من المفتاح المفتاح هذا حساس — لا تشاركه مع أحد، ولا ترفعه على GitHub أو أي مكان عام. هذا اللي يخلينا نحطه في ملف .env ونحط الـ .env داخل .gitignore.
  3. Claude راح يسوي التالي تلقائيًا:
    • ينشئ ملف .env داخل المشروع ويحط فيه المفتاح
    • ينشئ/يحدّث ملف .gitignore ويضيف .env فيه
    • يأكد إن كل شي جاهز
    راح تشوف ملفين جديدين في شجرة الملفات.
  4. لا تفتح ملف .env أبدًا أمام أحد — يحتوي على مفتاحك. خله مغلق دايمًا.
    معلومة تقنية: .gitignore ملف .gitignore هو ملف خاص يقول لـ Git "تجاهل هذي الملفات لما تشارك المشروع". وضع .env فيه قاعدة عالمية — كل مطوّر في العالم يتبعها. للتو تعلّمت ممارسة احترافية حقيقية.
ليش نحط المفتاح داخل القالب ملف .env الآن جزء من القالب. لما ننسخ المجلد لمشروع جديد (المرحلة 9)، المفتاح ييجي معه — تركيب لمرة وحدة، استخدام لانهائي.
المرحلة 8

إضافة صورة مرجعية لـ assets/

نحط صورة واحدة كمرجع داخل القالب — مثال يبدأ منه أي مشروع جديد. تقدر تبدّلها لاحقًا.

  1. جهّز صورة مرجعية (PNG أو JPG، نظيفة).
  2. اسحب الصورة من Finder إلى شجرة الملفات في VS Code، حطها داخل assets/references/.
  3. سمّها reference.jpg (اضغط زر الفأرة الأيمن → Rename) — يخلي المسار بسيط دايمًا.
لما تبدأ مشروع حقيقي تبدّل الصورة بصورة موديل، منتج، أو مرجع براند — حسب المشروع. المسار يبقى نفسه، فالقالب يشتغل دايمًا.
المرحلة 9 · اللحظة السحرية

تكرار القالب لمشروع جديد
