STANDARD OPERATING PROCEDURE
Freebie Creation Workflow
From post idea to public Drive link — full end-to-end process
AUTO Claude handles this step
MANUAL Majid handles this step
The Workflow
1
MANUAL Trigger the skill
Say: "Create a freebie for [post or topic]" and specify the freebie type:
mini-guide  ·  prompt-pack  ·  link  ·  template
2
AUTO Claude asks clarifying questions
Hook / aha moment · post angle · audience level · link or resource URL if applicable. Claude only asks what's missing — no redundant questions.
3
MANUAL Answer the questions
Brief answers are enough. Claude fills in the gaps using context from your brand and voice guidelines.
4
AUTO Claude writes the full freebie content
Written in Saudi dialect · mentor tone · following the standard structure:
Label → Title → Subtitle → Workflow link (if applicable) → الفكرة → Content → Closing note → تواصل معي → صنّاع الإلهام ✦
5
MANUAL Review the content
Read through and request any changes by number. When satisfied, say "go ahead."
6
AUTO Claude generates the branded HTML file
Saved to freebies-drafts/ · Dark background #07070F · Heritage Gold accents · Gumela Arabic font · MA Learn white logo · RTL A4 layout · Gold top/bottom bars · Grain texture overlay
7
AUTO Claude opens the file in the browser
The HTML file opens automatically for visual review.
8
MANUAL Export to PDF
Browser → File → Print → Save as PDF → Save to freebies-drafts/ folder.
Filename will be auto-detected by Claude in the next step.
9
AUTO Claude uploads the PDF to Google Drive
Detects the new PDF in freebies-drafts/ · uploads to the MA Learn freebies folder · sets sharing to "anyone with link can view."
10
AUTO Claude returns the shareable link
The public Drive link is ready to paste into your post, story, or WhatsApp broadcast.
STEP BREAKDOWN — AUTOMATED vs MANUAL

Automated: Steps 2, 4, 6, 7, 9, 10  ·  Manual: Steps 1, 3, 5, 8

The only unavoidable manual step is the PDF export (Step 8) — browser security prevents automated printing. Every other step runs automatically.

Final output → Public Google Drive PDF link, ready to share.
