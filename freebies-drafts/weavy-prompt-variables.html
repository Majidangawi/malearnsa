الفكرة

كتبت بروومت كامل — الإضاءة صح، الزاوية صح، الإحساس صح — وبعدين ما عجبك لون تيشيرت الموديل. رحت تدور على الكلمة، عدّلت، أعدت التشغيل، وطلع شي ثاني خربط عليك كل شي.

هذا مو خطأ في الـ AI — هذا خطأ في الطريقة. لما بروومتك ما عنده هيكل، أي تعديل بسيط يصير مغامرة.

الـ Prompt Variables في Weavy حلّت هذي المشكلة. تقدر تحدد أي جزء من بروومتك وتحوّله لمتغيّر تتحكم فيه بشكل مستقل — بدون ما تلمس باقي البروومت. تحكّم أكثر، دقة أكثر، سرعة أكثر — كل مرة.

١
افتح Weavy وأضف Prompt Node
٢

مثال: لون الملابس، نوع الإضاءة، خلفية المشهد
٤
اضغط Add Variable
راح يظهر Input Connector على الـ node
٥
أضف Prompt Node ثاني — هذا هو المتغيّر
٦
وصّل الـ Output Connector للـ Input Connector في الأول
٧
اكتب أي شي في الـ node الثاني
اللي تكتبه يؤثر مباشرة على الجزء اللي اخترته — بدون ما تعدّل أي شي ثاني
كل متغيّر تضيفه = قرار جمالي تتحكم فيه بدقة  ·  ابنِ بروومتك مرة وتحكّم فيه للأبد
