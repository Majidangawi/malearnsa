# Instagram Reel — Chat Launch

**Goal:** show the feature in action. 15–20 seconds. Demo > explanation.

## Hook (0–2s)

**Visual:** screen recording of lesson opening, Discussion tab empty, cursor hovers on it.
**Text overlay:** "التعلم ما يحصل في الصمت"
**Voiceover (optional):** silent, let the text + motion carry it

## Demo (2–12s)

Screen recording:
1. Click Discussion tab → empty state with "كن أول من يشارك فكرة"
2. Click composer → type "كيف اختار الإضاءة المناسبة؟"
3. Click send → message appears, animated in
4. Cut to: Majid's reply appears (with gold border + ✓ badge)
5. Hover on Majid's message → pin icon → click → message jumps to top as pinned
6. Switch to Pinned tab → pinned message visible with gold background

**Text overlays (appear/disappear on each action):**
- "اسأل"
- "شاركنا سؤالك"
- "أرد عليك"
- "الأجوبة المهمة تبقى مثبتة"

## CTA (12–18s)

**Visual:** zoom out to the player layout, gold underline animates across the Discussion tab.
**Text overlay (center):** "افتح أي درس — جربه"
**Voiceover:** none. Let the visual finish.

## Style notes

- No jump cuts. Smooth transitions between clicks.
- Record at 60fps, export at 30fps for Reel (smoother feel).
- Keep screen-record zoom tight — show the chat panel + tab, crop out unrelated UI.
- Cairo 700 for overlays, gold (#C9A84C) on dark ink background.
- End frame: full-width gold hairline + "MA Learn" lockup (subtle)
