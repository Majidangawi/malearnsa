MA Design System V4

“Poster-dark × chunky rounded.” One warm ground, one inspiration orange, one calm lavender, Gumela for the voice, Cairo for the words. Every new page, site, and PDF for MA Learn and Majid Angawi consumes these tokens — never a private copy.

Principles

Five decisions that make a page read as ours before a single word is read.

01

One warm ground

The page is a poster in a dark room, not a screen. Backgrounds are warm browns — #151009 — never pure black. Light comes from one direction (the hero glow) and falls off.

02

One inspiration orange

Accent is a single hot orange used for the thing you want the eye to land on — the CTA, the highlighted word, the live state. It is loud on purpose, so it is used sparingly (≈10% of any view).

03

Lavender is the calm counterpoint

The second family — foundations, community, “included” value — is lavender. It never competes with orange for the CTA; it cools a section down.

04

Chunky, rounded, airy

Big radii (22–34px), 1.5px lines, pill buttons, generous section rhythm (88–176px). Everything is centered by default. Nothing is cramped.

05

Gumela speaks, Cairo explains

Gumela Arabic Bold for every heading, name, and number that carries the voice. Cairo for all running text, UI and buttons. Arabic first, Latin brand names stay Latin.

RTL

Arabic-native, not translated

Every layout is designed in RTL. Use logical properties (inset-inline-start, margin-inline), never left/right. Marquees and media tracks are forced LTR internally.

Color

Click any swatch to copy its token. Ratio guide for any view: ~70% surfaces · ~20% ink & lines · ~10% accent. Lavender replaces accent in a section, never joins it.

Rules

Do
  • Arabic is primary; Latin brand names stay Latin (MA Learn, Midjourney, AI) wrapped in .en.
  • Arabic-Indic numerals for dates and counts in copy (٢٥–٢٧ أغسطس); Latin digits for prices, stats and code (1,399 SAR · 16).
  • Line-height 1.75–2.0 for Arabic body; 1.4 for display.
  • Cairo weights: 400 body · 600 rows · 700 chips · 800 buttons/labels · 900 numbers in pills.
Don't
  • No all-caps Arabic. Uppercase only for short Latin labels with letter-spacing.
  • No system fonts, no Tajawal/Almarai/Noto substitutes. If Gumela fails, Cairo carries the heading.
  • No letter-spacing on Arabic text.
  • Never write كوهورت — the word is دفعة.

Motion

One easing curve for everything that moves. Hover lifts 2px. Sections reveal once, 26px up over 800ms. Reduced-motion collapses all of it.

TokenValueUse
--easecubic-bezier(.22, 1, .36, 1)every transition and reveal
--dur-fast150mscolor, border, focus
--dur-med250mshover lift, chevrons, chips
--dur-slow500mscard lift, sticky bar in/out
--dur-reveal800ms.rv → .rv.in scroll reveal (opacity + 26px)
--lift / --lift-cardtranslateY(−2px) / translateY(−4px)button · card hover
bob keyframe1.6s infinite, 7px“scroll to why” arrow only
Do
  • Reveal sections once as they enter (IntersectionObserver adds .in).
  • Marquees: seamless loop, JS-measured offset, LTR on wrapper AND track, masked edges.
  • Pulse only for live urgency (countdown seconds, LIVE badge) — 1–2s, opacity or ≤ 6% scale.
Don't
  • No bounce, no spring overshoot, no parallax.
  • No animated gradients or moving glows.
  • No motion on text lines other than the reveal.

Rules

Non-negotiables for anyone — human or agent — shipping a surface for MA Learn or Majid Angawi.

Always
  • Link tokens.css or ma-v4.css from the canonical URL. A page that redeclares tokens is a bug.
  • One primary CTA per view. Orange belongs to it.
  • Design RTL-first; verify at 390px and 1440px.
  • Reduced-motion and keyboard focus must work — the tokens already handle both.
  • Real copy, real numbers. Placeholders use .ph-slot, never lorem ipsum.
  • Propose a new token or component here first; then use it. The changelog records every addition.
Never
  • Heritage gold, pure black, pure white, or any new hue.
  • Gumela in body text or buttons; Cairo Bold as a page H1.
  • Square corners on interactive elements. Radius < 10px on anything clickable.
  • Two accent buttons side by side. Orange next to lavender inside one component.
  • Drop-shadow on text; glow on anything that is not the hero or the primary button.
  • False scarcity in copy (“ما ينعاد”). Internal acronyms (CIW, ITCAI, T3) in public. كوهورت instead of دفعة.
